# 选题审查员（idea-checker）架构设计文档

**版本**：V2.1
**创建时间**：2026-09-06

## 核心架构

### 三层架构

```
触发器层 → 核心层（纯逻辑） → AI执行层（双模式） → 输出提醒
```

### 触发器层
- **文件监控**：watchdog监控智能体会话目录，新项目自动触发
- **桌面宠物**：PyQt6透明窗口，点击弹窗审查
- **CLI**：命令行直接输入想法
- **MCP服务器**：暴露check_idea工具

### 核心层
- 读取项目信息 → 拆解 → 搜索 → 分析 → 生成报告
- AI自主判断停止时机，不硬编码搜索轮次

### AI执行层（双模式）
- **主：智能体框架**（用户已接入的AutoGPT/CrewAI/豆包等）
- **降级：直接调LLM API**（OpenAI兼容，用户填key）

### LLM驱动的目录发现器
- 脚本只读文件系统，LLM做语义判断
- 自动识别全平台智能体框架，不硬编码列表
- 启动时扫描一次，日常用watchdog事件驱动
